# Detective Game Project

**Genre:** Narrative-driven Detective Adventure
**Perspective:** First-person
**Engine:** Unity (Recommended)
**Target Audience:** Mature audiences (17+)

## 🎯 Project Vision

A morality-driven detective game where every choice matters. Play as Alex Raines, a former cop turned private investigator, navigating a corrupt city while deciding between justice and survival.

## 🎮 Core Features

- **3 Chapters** with 3 cases each
- **Morality System** affecting skills, relationships, and endings
- **Memory Fragment System** revealing protagonist's past
- **Investigation Mechanics** with evidence gathering and puzzles
- **Multiple Endings** based on player choices
